## Cryptography Practice Project (Version 1)

A beginner-level Python CLI project created for learning and practicing basic programming concepts. This project implements a simple custom encryption and decryption system using string manipulation and file handling.

The goal of this version is to understand how data can be transformed, stored, and retrieved through basic Python logic. It is not intended for real-world security use.

---

## Technologies Used

* Python 3
* String manipulation
* File handling
* Command Line Interface (CLI)

---

## Features

* Simple custom encryption algorithm (basic character shifting and reversing)
* Decryption of the encoded text back to original form
* Menu-based user interaction in terminal
* Saving encrypted and decrypted results into text files

---

## Purpose

This project was built as a practice exercise to improve understanding of:

* Python functions
* Conditional statements
* User input handling
* Basic data processing logic

---

## Note

This is Version 1 of the project and focuses on learning fundamentals. Future versions may include improvements in structure, error handling, and code optimization.
