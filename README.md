## Cryptography Practice Project (Version 1)

A beginner-level Python CLI project created for learning and practicing basic programming concepts. This project implements a simple custom encryption and decryption system using string manipulation and file handling.

The main goal is to understand how data can be transformed, stored, and retrieved using Python logic. This project is not intended for real-world security use.

---

## Technologies Used

* Python 3
* colorama (for colored terminal output)
* String manipulation
* File handling
* Command Line Interface (CLI)

---

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/your-repo-name.git
cd your-repo-name
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

---

## How to Run

### Run the project:

```bash
python Main.py
```

or (if needed):

```bash
python3 Main.py
```

---

## How to Use

1. Run the program in the terminal.
2. A menu will appear.
3. Choose an option:

   * Encrypt text/password
   * Decrypt encrypted text
4. Enter your input.
5. The result will be shown in the terminal and saved automatically in text files.

---

## Features

* Simple custom encryption (string shifting + reversing)
* Decryption back to original text
* Menu-based CLI system
* Colored terminal output using `colorama`
* Saves results into text files
